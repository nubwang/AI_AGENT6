# 独立阶段采集按钮方案

## 目标

在采集管理页面增加 4 个独立按钮，分别对应 4 个阶段，可以单独触发某个阶段的采集，而不必每次都跑全量 4 个阶段。

## 改动方案

### 1. 后端改动 (`backend/app/api/ws.py`)

**现状**：`run_full_collection()` 依次调用 `stage1_basic()` → `stage2_daily()` → `stage3_stocks()` → `stage4_extra()`

**改动**：

- 将 `run_full_collection()` 拆分为可独立调用的 4 个阶段函数 + 1 个全量函数
- 每个阶段函数有自己的 `_running` 状态标记，互不干扰
- `run_full_collection()` 改为依次调用 4 个阶段（保持向后兼容）

### 2. 后端改动 (`backend/app/api/data.py`)

添加 5 个新 POST 端点：

| 端点                               | 功能                    |
| ---------------------------------- | ----------------------- |
| `POST /api/v1/data/collect/stage1` | 仅执行阶段1（基础信息） |
| `POST /api/v1/data/collect/stage2` | 仅执行阶段2（日频批量） |
| `POST /api/v1/data/collect/stage3` | 仅执行阶段3（个股循环） |
| `POST /api/v1/data/collect/stage4` | 仅执行阶段4（补充数据） |
| `POST /api/v1/data/collect/all`    | 全量采集（现有行为）    |

### 3. 前端改动 (`frontend/src/views/DataManage.vue`)

**控制栏增加 4 个阶段按钮**：

```
[▶ 开始采集] [阶段1: 基础信息] [阶段2: 日频批量] [阶段3: 个股循环] [阶段4: 补充数据]
```

- 每个按钮独立 loading 状态
- 点击后调用对应 API
- 进度通过 WebSocket 实时更新（保持不变）

### 4. 前端 API 层 (`frontend/src/api/index.ts`)

添加 4 个新 API 函数：

```ts
export const collectStage1 = () => api.post("/data/collect/stage1");
export const collectStage2 = () => api.post("/data/collect/stage2");
export const collectStage3 = () => api.post("/data/collect/stage3");
export const collectStage4 = () => api.post("/data/collect/stage4");
```
