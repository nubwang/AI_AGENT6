## 二、行情数据（6个接口）

### 1. `daily` — 日线行情（基础积分）

> **积分**：基础积分 ✅ | **批量方式**：按 `trade_date` 全市场  
> **数据频率**：日频

| 字段         | 类型  | 含义                     | 量化用途      |
| ------------ | ----- | ------------------------ | ------------- |
| `ts_code`    | str   | 股票代码（如 600036.SH） | 主键          |
| `trade_date` | str   | 交易日 YYYYMMDD          | 主键          |
| `open`       | float | 开盘价                   | K线、技术指标 |
| `high`       | float | 最高价                   | 波幅分析      |
| `low`        | float | 最低价                   | 波幅分析      |
| `close`      | float | **收盘价**               | **核心字段**  |
| `pre_close`  | float | 前收盘价                 | 涨跌幅基准    |
| `change`     | float | 涨跌额                   | 绝对波动      |
| `pct_chg`    | float | 涨跌幅（%）              | **核心因子**  |
| `vol`        | float | 成交量（手）             | 量能分析      |
| `amount`     | float | 成交额（千元）           | 金额量能      |

---

### 2. `weekly` — 周线行情（基础积分）

> **积分**：基础积分 ✅ | **批量方式**：按 `trade_date` 或 `ts_code`

| 字段         | 含义                             |
| ------------ | -------------------------------- |
| `ts_code`    | 股票代码                         |
| `trade_date` | 周结束日期（每周最后一个交易日） |
| `open`       | 周开盘价                         |
| `high`       | 周最高价                         |
| `low`        | 周最低价                         |
| `close`      | 周收盘价                         |
| `vol`        | 周成交量                         |
| `amount`     | 周成交额                         |

---

### 3. `monthly` — 月线行情（基础积分）

结构同 `weekly`，按月末最后交易日汇总。

---

### 4. `adj_factor` — 复权因子（基础积分）

> **积分**：基础积分 ✅ | **批量方式**：按 `ts_code` 一次性拉全部历史

| 字段         | 含义         | 量化用途       |
| ------------ | ------------ | -------------- |
| `ts_code`    | 股票代码     | 主键           |
| `trade_date` | 交易日       | 主键           |
| `adj_factor` | **复权因子** | 手动计算复权价 |

**复权计算公式**：

- 前复权收盘价 = `close × adj_factor ÷ 最新adj_factor`
- 后复权收盘价 = `close × adj_factor`

> ⚠️ 推荐手动用 adj_factor 计算复权价，不要直接用 daily 接口的复权字段

---

### 5. `stk_limit` — 每日涨跌停价格（2000积分 ✅）

> **积分**：2000积分 ✅ | **批量方式**：✅ 按 `trade_date` 全市场

| 字段         | 含义       | 量化用途 |
| ------------ | ---------- | -------- |
| `ts_code`    | 股票代码   | 主键     |
| `trade_date` | 交易日     | 主键     |
| `up_limit`   | 当日涨停价 | 涨停检测 |
| `down_limit` | 当日跌停价 | 跌停检测 |

**衍生因子**：触及涨停/跌停判断、涨停封板率

---

### 6. `suspend_d` — 停复牌信息（基础/2000积分）

> **积分**：基础或2000积分 ✅ | 用于检测股票是否处于停牌状态

| 字段           | 含义                  | 量化用途                       |
| -------------- | --------------------- | ------------------------------ |
| `ts_code`      | 股票代码              |                                |
| `trade_date`   | 交易日                |                                |
| `suspend_flg`  | 停复牌标志：停牌/复牌 | **回测必备**，停牌期间不可交易 |
| `suspend_type` | 停牌类型              | 临时停牌/长期停牌              |
| `ann_date`     | 公告日期              |                                |

> ⚠️ **回测关键**：必须在回测中过滤停牌股票，否则会产生未来函数

### 8. `moneyflow` — 个股资金流向（2000积分 ✅⭐强烈推荐）

> **积分**：2000积分 ✅ | **批量方式**：✅ 按 `trade_date` 全市场

| 字段            | 含义                     | 量化用途         |
| --------------- | ------------------------ | ---------------- |
| `ts_code`       | 股票代码                 | 主键             |
| `trade_date`    | 交易日                   | 主键             |
| `buy_amount`    | 主力买入金额（元）       | 主力动向         |
| `buy_vol`       | 主力买入量（股）         | 主力动向         |
| `sell_amount`   | 主力卖出金额（元）       | 主力动向         |
| `sell_vol`      | 主力卖出量（股）         | 主力动向         |
| `net_amount`    | **主力净流入（元）**     | **核心资金因子** |
| `net_vol`       | 主力净流入量（股）       | 辅助验证         |
| `amount_lt`     | 大单买入金额（>100万）   | 大单追踪         |
| `vol_lt`        | 大单买入量               | 大单追踪         |
| `net_amount_lt` | 大单净流入               | 大单追踪         |
| `amount_mt`     | 中单买入金额（20-100万） | 中单追踪         |
| `vol_mt`        | 中单买入量               | 中单追踪         |
| `net_amount_mt` | 中单净流入               | 中单追踪         |
| `amount_st`     | 小单买入金额（<20万）    | 散户情绪         |
| `vol_st`        | 小单买入量               | 散户情绪         |
| `net_amount_st` | 小单净流入               | 散户情绪         |

> **量化因子**：主力净流入率 = `net_amount / (buy_amount + sell_amount)` × 100%  
> **策略**：连续3日主力净流入 > 0 且净流入率 > 10%

### 9. `block_trade` — 大宗交易（2000积分 ✅）

> **积分**：2000积分 ✅ | **批量方式**：✅ 按 `trade_date` 全市场

| 字段         | 含义                | 量化用途   |
| ------------ | ------------------- | ---------- |
| `ts_code`    | 股票代码            | 主键       |
| `trade_date` | 交易日期            | 主键       |
| `price`      | 成交价格（元）      | 折溢价计算 |
| `vol`        | 成交量（万股）      | 大宗规模   |
| `amount`     | 成交金额（万元）    | 大宗规模   |
| `buyer`      | 买方营业部/机构名称 | 席位跟踪   |
| `seller`     | 卖方营业部/机构名称 | 席位跟踪   |

> **衍生因子**：大宗折价率 = `price / 当日close - 1`，负值越大说明折价越深

| 积分等级 | 每分钟最大请求数 | 每次最大返回行数 |
| -------- | ---------------- | ---------------- |
| 2000积分 | **200次/分钟**   | 5000-6000行      |

**应对策略**：

```
每次请求后 sleep(0.3秒) → 每分钟上限200次
触发429限流 → 指数退避重试（1秒→2秒→4秒→8秒）
```

### 12.2 API按拉取方式分类

**分类A：按日期批量拉取（最高效，优先使用）**

| 接口          | 单次请求内容                 | 全量历史请求数 | 日增请求数 |
| ------------- | ---------------------------- | -------------- | ---------- |
| `daily`       | 某日全市场日线（~5000行）    | 3650次         | 1次        |
| `daily_basic` | 某日全市场指标（~5000行）    | 3650次         | 1次        |
| `moneyflow`   | 某日全市场资金流（~5000行）  | 3650次         | 1次        |
| `stk_limit`   | 某日全市场涨跌停（~5000行）  | 3650次         | 1次        |
| `block_trade` | 某日全市场大宗交易（几十行） | 3650次         | 1次        |
| `ths_daily`   | 某日全市场概念行情（~500行） | 3650次         | 1次        |

**分类B：按股票代码逐个拉取（需要循环5000只股票）**

| 接口                           | 单次请求内容         | 全量请求数 | 说明             |
| ------------------------------ | -------------------- | ---------- | ---------------- |
| `adj_factor`                   | 某只股票全部历史     | 5000次     | 一次性拉取全部   |
| `dividend`                     | 某只股票全部分红     | 5000次     | 一次性拉取       |
| `stk_holdernumber`             | 某只股票全部股东人数 | 5000次     | 一次性拉取       |
| `top10_holders`                | 前十大股东           | 5000次     | 一次性拉取       |
| `stk_holdertrade`              | 增减持               | 5000次     | 一次性拉取       |
| `income/balancesheet/cashflow` | 财务报表             | 5000次×3   | 季频，一次性拉取 |
| `fina_indicator`               | 财务指标             | 5000次     | 季频             |

### 12.3 首次全量回填方案（分3天执行）

```
第1天（约4小时）：
  trade_cal → stock_basic → concept系列
  → daily（2010-2024分批）
  → daily_basic（2010-2024分批）

第2天（约3小时）：
  → moneyflow（2010-2024分批）
  → stk_limit / block_trade
  → adj_factor / dividend / stk_holdernumber（个股循环）

第3天（约2小时）：
  → fina_indicator / forecast / express
  → income / balancesheet / cashflow
  → margin / limit_list / hsgt / index_daily
  → 剩余一次性数据
```

### 12.4 每日增量更新（每日18:00执行）

```
拉取接口：daily / daily_basic / moneyflow / stk_limit / block_trade
          / ths_daily / forecast / express / margin / limit_list
          / hsgt / index_daily / suspend_d

每日请求量：约14次（远低于200次/分钟限制）
预计耗时：约30秒
```

## 十三、5000积分不可用接口的替代方案

### 13.1 技术面因子 — 用TA-Lib自己计算 ✅

`daily` 表已有完整日线，用 TA-Lib 可计算200+个技术指标：

```python
import talib

factors = {
    'ma5': talib.SMA(close, 5),           # 均线
    'ma10': talib.SMA(close, 10),
    'ma20': talib.SMA(close, 20),
    'macd': talib.MACD(close),             # MACD
    'rsi_14': talib.RSI(close, 14),        # RSI
    'kdj': talib.STOCH(high, low, close),  # KDJ
    'boll': talib.BBANDS(close),           # 布林带
    'vol_ma5': talib.SMA(vol, 5),          # 均量
    'atr': talib.ATR(high, low, close, 14),# 波动率
    'adx': talib.ADX(high, low, close),    # 趋势强度
}
```

> ✅ 用TA-Lib自己算，比Tushare因子接口更灵活

### 13.2 涨跌停和炸板数据 — 用stk_limit+daily推导 ✅

| 指标     | 计算公式                              |
| -------- | ------------------------------------- |
| 触及涨停 | `high >= up_limit × 0.997`            |
| 封板     | `close >= up_limit × 0.997`           |
| 炸板     | 触及涨停但收盘未封住                  |
| 封板率   | `close / up_limit`（越接近1封得越死） |

### 13.3 筹码集中度 — 部分替代 ⚠️

| 可用替代                   | 不可用（舍弃）   |
| -------------------------- | ---------------- |
| 换手率、自由流通换手率     | 精确筹码价位分布 |
| 量比、股东人数变化率       | 获利盘比例       |
| 均线偏离度（替代筹码成本） | 平均持仓成本     |

### 13.4 完全舍弃的接口

| 接口                              | 原因                   |
| --------------------------------- | ---------------------- |
| **margin_detail**（融资融券明细） | 5000积分，无低成本替代 |
| 每日筹码分布                      | 需要Level-2逐笔数据    |
| 股票技术面因子(专业版)            | 5000积分               |
