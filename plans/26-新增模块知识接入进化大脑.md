# 26 - 新增模块知识接入进化大脑（把"模块产出"接成"神经"）

> 用户诉求：**"新增的这些都写入进化大脑了么？都成大脑的神经了么？使选股准确率大大提升。"**
>
> 本文是这份诉求的**核查记录 + 接线规划 + 执行台账**。结论先说：

## 一、核查：什么是"接入进化大脑"

私有域知识库（EKB，plans/21）是进化大脑的长期记忆，唯一真源为
`backend/data/evolution_kb.sqlite`。一个模块的产出要算"接上了神经"，必须**四段全通**：

| 段     | 含义                                                          | 判定                                                        |
| ------ | ------------------------------------------------------------- | ----------------------------------------------------------- |
| ① 写入 | 产物 → EKB 档案（case/lesson/experiment/change/context/plan） | 库内有条目，带样本量与置信度                                |
| ② 蒸馏 | 可检索、可信度可更新（支持否证退役与升权）                    | `lesson` 有 `support.n`/`status`/`confidence`               |
| ③ 读取 | 被 L0 摘要、综合分析上下文、检索、提案前置校验取用            | `l0_text()` / `knowledge_txt()` / `search_lessons()` 能看到 |
| ④ 治理 | 幂等、只读原始文件、失败不阻塞、可审计                        | 二次执行条数不变；审计脚本可核对                            |

当新因子加进打分），并误把"毛收益/理想成交价"当真实能力。

## 三、接线规划（分五步，全部已执行）

### 步骤 1：证据接入层 `app/kb/kb_evidence.py`（新增）

只读挂引用（与 plans/21 §三"外部软知识库只读挂引用"同一处置原则）：

```
模块产物 JSON ──提取结论──> lesson(type=`evidence:<module>`，带 n/置信度/可操作 hint)
```

- 产物登记表 `ARTIFACTS`：**26 个产物**（见附录 A）
- 提取原则：**只搬结论与样本量**，不搬原始数据（30MB 的样本文件不进库）
- 无样本量一律按 n=1 → `candidate`（只作观察，守住宪法 C3：小样本不当规律）
- id 自建（`_slug` **保留数字**），避免 `ab_t1/t5/t10`、`h5/h20` 被
  `lesson_id()` 的数字归一化压成同一条（实测曾把 38 条压成 34 条）
- 幂等：确定性 id + upsert；`absorb_all(rebuild=True)` 支持口径升级后重建

### 步骤 2：读取侧打通（这是"神经"的关键）

| 位置                                                   | 改动                                                                 |
| ------------------------------------------------------ | -------------------------------------------------------------------- |
| `kb_store.query_lessons_by_type()`                     | 新增：按 type 前缀 SQL 直取（不解析全表，热路径可用）                |
| `kb_index.evidence_lessons()`                          | 新增：取 `evidence:*` + `discipline`，并归一化 `cases_n/total_n → n` |
| `kb_index.l0_block()/l0_text()`                        | 新增"实证结论"必读行（进化大脑每轮摘要都看到）                       |
| `kb_context.build_knowledge_context()/knowledge_txt()` | 注入实证结论段 + **硬规则⑤**（必须引用或解释为何不采纳）             |
| `kb_index.stats()`                                     | 新增 `plans` / `evidence` 计数                                       |
| `GET /evolve/kb/evidence`                              | 新增接口（前端看板与人工核对用）                                     |

### 步骤 3：自动持续接入

- `kb_context.distill_and_reindex()`（每日维护）内置 `kb_evidence.absorb_all()`
  → 模块产物更新后**自动变成神经**，无需人工
- `kb_ingest.import_external_kbs()` 同步接入 → 回填路径也覆盖
- `scripts/kb_absorb_evidence.py`（新增）：手动"跑完即入脑"

### 步骤 4：历史资产补录

| 脚本                                           | 作用                                                     |
| ---------------------------------------------- | -------------------------------------------------------- |
| `scripts/backfill_evolution_kb.py`             | 增加 `backfill_module_evidence()`                        |
| `scripts/backfill_backtest_history.py`（新增） | `data/backtest_results/*.json`（38 份）→ experiment 台账 |

并修复了 2 个**真实数据缺陷**：

1. `kb_ingest.ingest_backtest` 只读 `result["metrics"]`，而真实回测报告的指标在
   `performance` / `samples` / `ab_validation` → 台账 `hit_rate` 恒为 `None`
   （连实时回测记录也受影响）。现兼容三种来源，并记录 **AB 决策**（Go/No-Go）与原因。
2. 数据集指纹把 `samples`（dict）整体当样本量 → 任何字段变化都判"数据集变了"。
   现取 `total/n`。

### 步骤 5：可核对与可审计

- 审计脚本 `audit_evolution_kb.py` 增加"新增模块知识接入"章节（plan 条数 + 分模块证据数）
- 自证脚本 `scripts/verify_evolution_evidence_wiring.py`：8 项断言全 PASS
- 前端 `Evolution.vue`：新增"🔬 实证结论"表格 + 模块筛选 + 两张统计卡
  （实证结论 / 交易计划台账）

```

知识库总览：案例 359 / 教训 6793 / 实验 43 / 改动 10 / 交易计划 386 / 证据 90

```

关键实证结论示例（已能被进化大脑直接读到）：

- **自证**：`plans/25` OOS 超额与分层（唯一验收口径；为负即"瓶颈在选股端"）
- **买点**：突破成交率 88.6% 但超额 −0.95%；回踩成交率 64.0%、超额 +0.1%（n=87691）
- **洗盘**：T1/T5/T10 均无显著差异（p=0.344/0.680/0.742，n=448）→ 禁止当加分项
- **博弈特征**：FDR 通过才准用；未通过时写入"禁止加权"
- **纪律网格**：最优参数下期望仍 −2.20%、被洗出率 74% → 指向选股端
- **口径护栏**：HAC t 修正后失去显著性的结论（`t_overlap`）写入"不得作为提案依据"

## 五、这不等于"准确率立刻提升"（诚实边界）

接线消除的是三处**系统性损耗**：① 凭个案猜（信息不足）；② 重复验证已被否证方向
（浪费进化轮次、可能采纳假因子）；③ 用毛收益/理想成交价误判（成本口径入脑）。

准确率提升的实际路径是：进化大脑基于 **自证 OOS 超额 + 买点成交率 + FDR 结论 + 成本净收益**
去改**选股端**（信号/形态/过滤/打分），而不是只调纪律参数。接线让这条路第一次可走通。
